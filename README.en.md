<h1 align="center">Blue Archive · Character Memorial Lobby OST Reference</h1>

Quickly look up OST music from *Blue Archive* Character Memorial Lobby, with online preview and playback.

## Features

- Search by song or character name (Chinese / English)
- Online music preview (play / pause)
- Auto-display character info for the currently playing song
- Responsive layout for desktop and mobile

## Data Source

Character–song mapping data comes from [Kivotos Library](https://kivo.wiki/) and personal collection.

## [Live Demo](https://ost.starpole.cc.cd)

## Usage

```bash
# Install dependencies
npm install

# Development mode
npm run dev

# Production build
npm run build
```

The built files are located in the `dist/` directory and can be deployed to any static server.

## Tech Stack

- Vue 3 (Composition API + `<script setup>`)
- Vite
- [APlayer](https://github.com/DIYgod/APlayer) — HTML5 music player
